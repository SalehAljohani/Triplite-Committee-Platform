# Triplet Committee Platform (TCP)
## Project Overview
The Triplet Committee Platform (TCP) is a web-based solution designed to streamline the workflows of Taibah University's committees, specifically handling scholarship-related requests. TCP facilitates faster decision-making, accurate data processing, and a paperless environment. It was developed as part of our graduation project.
## Features
- **Automated Workflows:** Handles requests like scholarship extensions, new scholarship requests, and study delays.
- **Digital Signatures:** Allows committee members to sign documents electronically.
- **Request Tracking:** Track the status of scholarship applications in real-time.
- **Report Generation:** Automatically generates unified reports in PDF format.
- **Admin Dashboard:** Centralized control for managing users, boards, and requests.
## Tech Stack
- **Front-End:** ASP.NET Core, Bootstrap
- **Back-End:** C#, SQL Server
- **Version Control:** GitHub
- **Tools Used:** Visual Studio, Lucid Charts, Draw.io
